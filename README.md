## 概要

Next.js (App Router, TypeScript) と Supabase を組み合わせた最小構成のWebアプリです。`lib/supabase.ts` で Supabase クライアントを初期化し、トップページ (`app/page.tsx`) で Supabase への接続確認結果を表示します。

Supabase の接続情報は環境変数として `.env.local` に設定します(このファイルは Git 管理対象外です)。

```
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
